<objective>
Checkpoint persistence + resume across subprocess restarts (DMV3-08).

Purpose: Retire the stub-era `checkpoint_*.pt` / `final.pt` glob in `_find_latest_checkpoint`
in favor of the `embodied.Checkpoint` native `*.ckpt` format (D-09), and add a GPU-gated
restart-then-continue test that proves a second `run_dreamer_training` call with the same
`{task}_{obs_type}` dir resumes from the persisted step counter rather than restarting at 0.
This completes DMV3-08's "persist per task/obs-type AND resume across subprocess restarts"
requirement (40-01's `cp.load_or_save()` at construct time + 40-02's `cp.save()` at eval_every
produce the checkpoint this plan reads back).

This plan is autonomous:false because the resume test's GREEN requires a GPU + dreamerv3 + jax
— satisfied by the 40-04 CI dreamer-gpu job at merge time. Locally on macOS the resume test
SKIPs per INV-8 (the RED scaffold verifies the skipif fires on CPU).

Output: Updated `_find_latest_checkpoint` + `run_dreamer_training` checkpoint path refs in
`src/surg_rl/dreamer/training.py`, NEW `tests/dreamer/test_dreamerv3_checkpoint_resume.py`.
</objective>
