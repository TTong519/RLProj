<objective>
Thread checkpoint_dir into _find_latest_checkpoint and both call sites so the parent resume path actually finds checkpoints at a custom directory. The parent-resolved checkpoint_dir is already threaded to the child (81588c2), but _find_latest_checkpoint hardcodes models/dreamerv3/{task}_{obs_type} and ignores it, so with a custom checkpoint_dir + resume=True the parent's subprocess.load_checkpoint never fires (latest=None). This plan wires the parent side and verifies it with a CPU-runnable subprocess-stub test.

Purpose: Close the DMV3-08 resume-path gap surfaced by the v0.6.0 milestone audit (v0.6.0-MILESTONE-AUDIT.md:48-49,152) — the fragile defense-in-depth gap where the child cp.load_or_save() at subprocess.py:217 masks the broken parent path.
Output: _find_latest_checkpoint with additive checkpoint_dir param, both call sites updated, and a new CPU-runnable test file verifying the parent resume wiring without GPU/JAX.
</objective>
