## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] RED test failed for the wrong reason (MagicMock not JSON-serializable)**
- **Found during:** Task 1 (RED test creation)
- **Issue:** `run_dreamer_training` calls `subprocess.evaluate(...)` at the end and serializes the result into `training_metrics.json`; the MagicMock return raised `TypeError: Object of type MagicMock is not JSON serializable` at `json.dump`, so the test errored before reaching the `load_checkpoint` assertion — the RED failure would have been an unrelated crash, not the actual gap.
- **Fix:** Set `fake_sp.evaluate.return_value = {}` (JSON-serializable dict) so the test reaches the `load_checkpoint.assert_called_once_with(...)` assertion and fails there (0 calls vs expected 1 — the actual D-01/D-03 gap).
- **Files modified:** tests/dreamer/test_checkpoint_dir_resume_cpu.py
- **Verification:** RED re-run showed `AssertionError: Expected 'load_checkpoint' to be called once. Called 0 times.` — the correct RED failure mode; GREEN then passed.
- **Committed in:** f0d193f (RED commit, test-isolation fix applied before the first RED commit)
