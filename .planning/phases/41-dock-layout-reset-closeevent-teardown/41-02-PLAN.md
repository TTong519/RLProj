## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| editor → LLM provider (HTTP) | The LLM HTTP call crosses this boundary; the worker lives on a QThread. The teardown here is local (cooperative cancel + thread.quit + wait) — the HTTP call's own timeout/auth is unchanged. No new untrusted-input surface. |
| Qt event loop → worker QThread | The `aboutToClose` signal crosses from the main thread to slots; `stop()` touches `self._worker`/`self._thread` from the main thread (Qt-acceptable: setProperty is thread-safe, quit/wait are thread-safe). |
